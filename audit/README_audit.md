# Independent audit of data extraction

Auditor: Dr. Nur İlayda Genç, Koç University Hospital, İstanbul (internal medicine). No role in the design, searching, screening, extraction or analysis of the review. Audit returned 27 September 2026.

Files
- `Audit_extraction_table.xlsx`: the audit table as returned by the auditor. Sheet "Primary outcome values": the 14 outcome values (lean and fat mass; five primary trials and the two sensitivity-set trials) with, for each, the source document, table or figure and page, analysis population, estimand, comparison, sample sizes, value and 95% CI as reported, transformation applied and value entered in the analysis (white columns, authors), and the auditor's columns R to U (value confirmed Y/N, value read from the source, comments, initials and date). Sheet "Baseline LBM and n (Table 1)": the five baseline lean-mass values. Column V of the first sheet and the sheet "Change log (authors)" record the notes the authors added during the audit (exact PDF page numbers of the tables in the two clinical trial reports; a clarification that the standard errors are derived from the confidence intervals). The auditor's columns were never edited by the authors.
- `Auditor_statement_signed_2026-09-27.pdf`: the auditor's signed statement.

Sources given to the auditor: Look 2025 (Diabetes Obes Metab) with supplement; Wilding 2021 (NEJM) supplementary appendix; McCrimmon 2020 (Diabetologia); Novo Nordisk clinical trial reports NN2211-1572 (LEAD-2) and NN2211-1573 (LEAD-3), redacted versions publicly available at novonordisk-trials.com; Jendle 2009 (Diabetes Obes Metab); Lundgren 2021 (NEJM) supplementary appendix; Mok 2023 (JAMA Surg).

Note on sample sizes: the white columns of the audit table give the SUSTAIN-8 sample sizes as 53 / 61 (participants with an observed end-of-treatment scan inside the on-treatment observation period). After the audit package had been sent, the authors' own check (22 September 2026) led to reporting the analysis set of the confirmatory analysis instead (88 / 90, multiple imputation; 178 in Table 1 of the manuscript). `data_raw.csv` and the manuscript use 88 / 90; the audit table was not altered. No estimate uses n.

Outcome: 19 values checked; no discrepancy in any value. See Additional file 1, Section S10 and Table S10.
